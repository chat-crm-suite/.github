# Security policy

**English** · [Español](#política-de-seguridad)

## Supported versions

Security fixes are applied to the latest release on `main` of each repository.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately by either:

- GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) (the **Security** tab of the affected repository), or
- email to **chancanjeremiaron@gmail.com** with the subject `[SECURITY] chat-crm`.

Include the affected repository and version, the steps to reproduce and the impact you observed.
You will get an acknowledgement within **72 hours** and a status update within **7 days**. Once a fix is
released we will credit you, unless you prefer to stay anonymous.

# Política de seguridad

[English](#security-policy) · **Español**

## Versiones soportadas

Los arreglos de seguridad se aplican a la última versión publicada en `main` de cada repositorio.

## Reportar una vulnerabilidad

Por favor **no** abras un issue público. Repórtala de forma privada mediante:

- el [reporte privado de vulnerabilidades](https://docs.github.com/es/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) de GitHub (pestaña **Security** del repositorio afectado), o
- un email a **chancanjeremiaron@gmail.com** con el asunto `[SECURITY] chat-crm`.

Incluye el repositorio y la versión afectados, los pasos para reproducirla y el impacto observado.
Recibirás un acuse de recibo en **72 horas** y una actualización en **7 días**. Cuando se publique el
arreglo te daremos el crédito, salvo que prefieras quedar en el anonimato.
